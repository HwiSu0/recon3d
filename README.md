# 통로 3D 복원

불투명한 상자 속 호스에 철 현탁액을 흘리고, 바깥 자기장 센서 4대의 측정값으로 호스가 지나간 길을 3차원으로 복원하는 웹 프로그램입니다.

설치할 것이 없습니다. 페이지를 열고 Capstone CSV를 넣으면 브라우저 안에서 계산하고, 돌려 볼 수 있는 3D 결과를 보여 줍니다. 측정 파일은 서버로 전송되지 않습니다.

페이지 주소: <https://hwisu0.github.io/recon3d/>

## 사용법

1. **측정 파일**: Capstone에서 File > Export Data > Export to file로 저장한 CSV를 넣습니다. 여러 Run이 든 파일도 됩니다.
2. **실험 조건**: 기존 설정을 고르거나 설정 JSON을 연 뒤 이번 Run에 맞게 고칩니다.
3. **복원 시작**을 누릅니다. 끝나면 3D 결과가 오른쪽에 나타나고, HTML과 JSON으로 저장할 수 있습니다.

처음 실행할 때는 파이썬 실행 환경 약 40 MB를 내려받습니다. 다음부터는 브라우저에 저장된 것을 씁니다. 시험한 환경에서 전체 시간은 Run #40이 약 45초, Run #49가 약 3분 30초였고, 컴퓨터 성능에 따라 달라집니다.

### 자주 바꾸는 설정

| 화면 항목 | JSON 키 | 뜻 |
| --- | --- | --- |
| Run 번호 | `run` | CSV 안의 Run 번호 |
| 기준 구간 | `baseline` | 철이 들어오기 전, 아무도 건드리지 않은 구간 [시작, 끝] 초 |
| 분석 구간 | `t_window` | 분석할 구간 [시작, 끝] 초. 흔들린 구간은 뺍니다 |
| 뺄 구간 | `mask` | 센서별로 뺄 구간. 예: `{"S2": [[69, 999]]}` |
| 철 도착 예상 시각 | `t_front_guess` | 철이 상자에 올 것 같은 시각. 대략이면 되고 비워도 됩니다 |
| 센서 위치 | `sensors` | (a, b, c) cm. 정확할수록 좋습니다 |
| 호스 안지름 | `hose_mm` | `{"stem": 3, "branches": [3, 3]}` |
| 주사기~입구 호스 길이 | `upstream_len` | cm |
| 실제 경로와 비교 | `truth` | 실제 경로를 알 때만 씁니다. 블라인드 시험이면 끕니다 |

좌표 (a, b, c)는 a가 입구면에서 출구 쪽, b가 앞면(S3 쪽)에서 안쪽, c가 탁자에서 높이입니다. 그 밖의 항목은 화면의 **설정 전체 보기 (JSON)** 에서 고칩니다. 새 설정을 목록에 넣으려면 파일을 `configs/`에 두고 `configs/index.json`에 한 줄 추가합니다.

### 결과 읽는 법

- **χ²/N**: 1에 가까울수록 잡음 수준까지 맞은 것입니다. "철 없다고 볼 때" 값보다 많이 작아야 의미가 있습니다.
- **실제 경로로 맞출 때 χ²/N**: 복원 경로의 값보다 크게 높지 않아야 합니다. 틀린 경로의 χ²/N이 더 낮다면 신호가 부족해 복원을 믿을 수 없다는 뜻입니다.
- **다른 후보**: 가는 반투명 관으로 그려집니다. 후보끼리 많이 다른 곳이 불확실한 곳입니다.
- **아래 그래프**: 옅은 선이 측정, 진한 선이 모델입니다. 겹칠수록 잘 맞은 것입니다.

## 작동 방식

```
index.html, assets/   화면
assets/worker.js      Pyodide(웹어셈블리 파이썬)로 계산을 돌리는 워커
engine/recon3d.py     복원 프로그램 원본
engine/template.html  결과 3D 화면
configs/              Run별 설정
```

웹 버전이 계산을 다시 구현한 것이 아니라 `engine/recon3d.py`를 수정 없이 브라우저에서 실행합니다. 그래서 프로그램을 고칠 때도 이 파일만 고치면 됩니다.

`engine/template.html`은 원본에서 한 줄만 고쳤습니다. 숨겨 둔 예비 그림이 자리를 차지해 3D 화면과 버튼 사이에 큰 빈 공간이 생기던 문제입니다.

Pyodide는 jsDelivr에서 불러오므로 학교 망에서 `cdn.jsdelivr.net`이 막혀 있으면 계산이 시작되지 않습니다. 버전은 `assets/worker.js` 맨 위에 고정되어 있습니다.

### 파이썬 결과와 비교

같은 설정과 데이터로 일반 파이썬(numpy 2.5, scipy 1.18)과 이 페이지(Pyodide 314.0.7)를 비교했습니다.

| | 일반 파이썬 | 웹 페이지 |
| --- | --- | --- |
| Run #40 χ²/N | 4.619 | 4.619 |
| Run #40 실제 경로와 차이 (평균 / 최대) | 0.96 / 2.01 cm | 0.96 / 2.01 cm |
| Run #49 χ²/N | 1.547 | 1.547 |
| Run #49 실제 경로로 맞출 때 χ²/N | 1.656 | 1.656 |
| Run #49 입구→분기점 차이 (평균 / 최대) | 2.42 / 5.89 cm | 2.42 / 5.89 cm |

Run #40은 저장되는 모든 값이 0.0004% 이내로 같습니다. Run #49는 최종 답의 값이 0.9% 이내로 같습니다. 가장 큰 차이는 앞머리 폭 τ입니다. Run #49처럼 신호가 약하면 차순위 후보의 값은 더 달라질 수 있습니다. 부동소수점 계산 라이브러리가 달라서 생기는 차이입니다.

## 내 컴퓨터에서 실행하기

웹 대신 일반 파이썬으로도 돌릴 수 있습니다.

```
python -m pip install numpy pandas scipy
python engine/recon3d.py configs/config_r49.json
```

CSV는 설정의 `csv` 경로에 두고, 결과는 `out` 경로에 `.json`과 `.html`로 저장됩니다.
